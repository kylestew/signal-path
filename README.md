# Signal Path

Small static site about analog electronics, Eurorack, and audio circuits.

## Structure

- `index.html` — topic list
- `topics/` — standalone topic pages
- `assets/style.css` — shared site styles

## Current Topics

- AC coupling
- Voltage follower / buffer
- RC lowpass filter
- Voltage control / CV

## Development

Plain HTML and CSS. No build step for the site itself.
