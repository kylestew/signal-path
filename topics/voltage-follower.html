Voltage Follower

Unity-gain buffer — same voltage out, but with muscle behind it

What It Does

An op-amp with its output wired straight back to the inverting input. Gain is exactly 1× — the output voltage follows the input. The point isn't amplification, it's impedance transformation: high input impedance in, low output impedance out.

Why It Matters

  • Prevents a low-impedance load from dragging down a high-impedance source
  • Isolates circuit stages so they don't interfere with each other
  • Lets sensitive signals (like from a guitar pickup or sensor) drive cables and downstream circuits without signal loss

The Circuit

Input goes to the non-inverting (+) pin. Output connects directly back to the inverting (−) pin — 100% negative feedback. Output tracks input exactly.

Buffer vs Follower

"Voltage follower" and "buffer" mean the same thing in practice. "Follower" describes the behavior (output follows input). "Buffer" describes the purpose (isolate stages). An emitter follower (BJT) does the same job — slightly less precise but no op-amp needed.

When You Need One

  • Before a long cable run — cable capacitance won't load the source
  • After a potentiometer — so the pot's position doesn't change depending on what's downstream
  • Between a high-impedance sensor/pickup and a low-impedance input
  • At eurorack module outputs — standardizes output impedance (~1kΩ)
